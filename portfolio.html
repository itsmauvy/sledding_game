게임의 세계관과 캐릭터를 브라우저 안에서 직접 느낄 수 있도록 설계했습니다.

기획 배경

왜 이 사이트를
만들었나

단순한 게임 정보 나열이 아닌, 처음 접하는 유저가 "이 게임 재밌겠다"는 감정을 느끼고 자연스럽게 스팀으로 이동하도록 설계한 감성 중심의 프로모션 사이트입니다.

🎮

출시 프로모션

스팀·Xbox 얼리 액세스 출시를 앞두고, 유저들이 게임을 발견했을 때 첫인상을 결정할 랜딩 페이지가 필요했습니다. SNS와 유튜브 유입 유저를 스팀 구매 전환으로 이어주는 역할을 담당합니다.

🐸

캐릭터 중심 경험

Sledding Game의 가장 큰 매력은 귀여운 캐릭터들과 함께하는 멀티플레이입니다. 텍스트보다 영상과 인터랙션으로 게임의 재미를 직접 체험하게 하는 것을 핵심 목표로 설정했습니다.

🏔️

게임 세계관을 웹으로

사이트 자체가 게임의 연장선이 되도록 설계했습니다. 눈밭·썰매 트랙·개구리 캐릭터가 UI 곳곳에 녹아들어, 방문자가 페이지를 탐색하는 것 자체가 게임적 경험이 되도록 했습니다. 스크롤을 따라다니는 개구리 마스코트, 썰매 모양 스크롤바, 물결 모양의 섹션 구분선이 그 예시입니다.

주요 기능

왜 이렇게
만들었나

각 섹션은 단순한 정보 전달이 아닌, 유저의 감정과 행동을 유도하는 목적으로 설계했습니다.

1

히어로 섹션 + 트레일러 모달

풀스크린 배경으로 첫인상을 강하게 남기고, "게임 영상 보기" CTA로 트레일러를 인페이지 모달로 재생합니다. 외부 유튜브로 이탈시키지 않고 사이트 내에서 경험을 완결해 이탈률을 줄이는 구조입니다.

전환율 최적화
2

게임 소개 슬라이더

꾸미기·미니게임·낚시 3가지 핵심 콘텐츠를 탭 슬라이더로 구성했습니다. 각 탭마다 실제 게임 영상을 autoplay로 보여줘 텍스트 없이도 게임의 재미를 직관적으로 전달합니다. 데스크톱은 GSAP 모션, 모바일은 CSS transition으로 각각 최적화했습니다.

영상 중심 설명 GSAP / CSS animation
3

인터랙티브 캐릭터 소개

13종의 캐릭터를 썸네일 그리드로 나열하고 선택 시 대형 이미지로 전환됩니다. CSS sprite sheet(미니 프로필.png)로 썸네일을 구현해 이미지 요청 수를 최소화했습니다. 데스크톱에서는 클릭·드래그 인터랙션, 모바일에서는 캐러셀로 각각 최적 UX를 제공합니다.

CSS Sprite Sheet 드래그 인터랙션
4

미디어 섹션 + 썰매 스크롤바

영상/이미지 탭 전환과 함께, 가로 스크롤 위치를 게임 캐릭터가 썰매를 타고 이동하는 커스텀 스크롤바로 시각화했습니다. 기능과 게임 세계관을 동시에 녹인 UI 디테일입니다.

커스텀 스크롤바 브랜드 경험
5

뉴스 섹션 + 키보드 탐색

방향키로 뉴스 카드 간 이동이 가능하고, 개구리 캐릭터가 선택된 카드 위를 뛰어다닙니다. 접근성(aria)과 재미를 동시에 고려한 인터랙션으로, 단순한 정보 나열이 아닌 게임적 요소를 뉴스 섹션에도 적용했습니다.

접근성 (aria) 키보드 탐색
6

스크롤 개구리 마스코트

ScrollTrigger로 스크롤 위치를 추적해 개구리 마스코트가 화면을 따라다닙니다. 브랜드 캐릭터를 자연스럽게 노출하면서 사이트 탐색을 재미있게 만드는 장치입니다. 모바일에서는 레이아웃 영향을 방지하기 위해 숨김 처리했습니다.

GSAP ScrollTrigger 마스코트 경험
